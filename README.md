# КВ помощник для Forge of Empires

Скрипты для Tampermonkey: помощник по застройке и сбору в Квантовых вторжениях и журнал наград квантовой карты.
Оба скрипта только читают данные игры и подсказывают шаги — сами ничего не нажимают.

## Установка

1. Установите расширение **Tampermonkey** в Chrome, Edge, Opera или Vivaldi.
2. В настройках расширений браузера включите «Режим разработчика», а у Tampermonkey в «Подробнее» — «Разрешить пользовательские скрипты» (если такой пункт есть).
3. Откройте ссылку и нажмите «Установить»:
   - Помощник: https://raw.githubusercontent.com/retrymister-ui/foe-qi-helper/main/foe-qi-helper.user.js
   - Журнал наград: https://raw.githubusercontent.com/retrymister-ui/foe-qi-helper/main/foe-qi-reward-log.user.js
4. Перезагрузите игру (F5) и зайдите в квантовое поселение. Справа появится коричневая кнопка с кристаллом.

## Активация

При первом запуске помощник покажет номер аккаунта. Отправьте его владельцу помощника и вставьте полученный ключ.
Ключ работает только на том аккаунте, для которого выдан. На другом сервере — другой номер аккаунта и отдельный ключ.

## Обновления

Tampermonkey обновляет скрипты сам (по умолчанию раз в день). Обновить вручную: значок Tampermonkey → «Утилиты» → «Проверить обновления».
