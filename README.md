# КВ помощник для Forge of Empires

Скрипты для Tampermonkey: помощник по застройке и сбору в Квантовых вторжениях, журнал наград квантовой карты и логгер Полей битв гильдий.
Все скрипты только читают данные игры и подсказывают шаги — сами ничего не нажимают.

## Установка

1. Установите расширение **Tampermonkey** в Chrome, Edge, Opera или Vivaldi.
2. В настройках расширений браузера включите «Режим разработчика», а у Tampermonkey в «Подробнее» — «Разрешить пользовательские скрипты» (если такой пункт есть).
3. Откройте ссылку и нажмите «Установить»:
   - Помощник: https://raw.githubusercontent.com/retrymister-ui/foe-qi-helper/main/foe-qi-helper.user.js
   - Журнал наград: https://raw.githubusercontent.com/retrymister-ui/foe-qi-helper/main/foe-qi-reward-log.user.js
   - Логгер ПБГ: https://raw.githubusercontent.com/retrymister-ui/foe-qi-helper/main/foe-gbg-logger.user.js
4. Перезагрузите игру (F5) и зайдите в квантовое поселение. Справа появится коричневая кнопка с кристаллом.

## Логгер ПБГ

Ключ не нужен. На Полях битв появляется круглый значок со скрещёнными мечами, цифра на нём — текущая усталость (красная — с 50 уровня).
Значок можно перетащить в любое место — положение запоминается. Клик по значку открывает панель рядом с ним, кнопка «—» сворачивает её обратно.
На вкладке «Карта» вверху — «Скоро откроются»: таймер посекундный в последнюю минуту, отмечены провинции, соседние с нашими (на них можно напасть). За 60 и 10 секунд до открытия соседней чужой провинции звучит сигнал, а на значке идёт обратный отсчёт.
С 150 уровня усталости сложность больше не растёт: логгер показывает «MAX», а провинции сортирует по времени открытия, а не по шансу усталости.
Вне Полей битв значок скрыт. Чтобы открыть панель в городе (например, для экспорта), нажмите Alt+G; показ везде включается в настройках на вкладке «Экспорт».
Вкладки: сводка за сессию (бои, монеты, шанс награды, усталость), карта (чужие провинции по шансу усталости), враги (кто и как быстро бьёт провинции, тревога при атаке на наши), кривая усталости, награды, бои, новые поля протокола и экспорт в JSON/CSV.
Данные сессии хранятся в браузере и переживают перезагрузку игры до конца раунда ПБГ.

## Активация

Нужна только для КВ помощника. При первом запуске он покажет номер аккаунта. Отправьте его владельцу помощника и вставьте полученный ключ.
Ключ работает только на том аккаунте, для которого выдан. На другом сервере — другой номер аккаунта и отдельный ключ.

## Обновления

Tampermonkey обновляет скрипты сам (по умолчанию раз в день). Обновить вручную: значок Tampermonkey → «Утилиты» → «Проверить обновления».
